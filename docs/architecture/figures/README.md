Notation is UML 2.5 only. The one accent colour marks the gRPC path to Booking. The smallest text
is 32 px at 1600 px width, which is about 9 pt when the image is shown at A4 text width (16 cm).
In Figure 7.1 the internal service-to-service calls are listed in one note instead of drawn as
paths, to keep the diagram readable.

## Regenerate

The SVGs are generated by the scripts in `source/` (Python 3 with Pillow, and the Liberation Sans
font for text measurement). Run from this folder:

```sh
python3 source/fig61.py
python3 source/fig71.py
node source/render.js fig-6-1-gateway-components.svg fig-7-1-service-discovery.svg
```

`render.js` uses Playwright with Chromium. The committed PNGs were then reduced to a 32-colour
palette with Pillow to keep them small; this does not change how they look.
